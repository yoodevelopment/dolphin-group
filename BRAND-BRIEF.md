# Brand Brief

## Brand core

- Brand promise: Dolphin Group помогает бизнесу создавать цифровые продукты, автоматизировать процессы и объединять IT-системы в единую инфраструктуру.
- Personality: Современный, технологичный, надёжный, понятный и ориентированный на бизнес-результат.
- Audience perception today: Новая или развивающаяся IT-компания, которой необходимо понятно представить свои компетенции и услуги.
- Desired audience perception: Надёжный технологический партнёр, способный реализовать проект от идеи и MVP до интеграций, автоматизации и облачной инфраструктуры.
- Competitive distinction: Комплексный подход — разработка, интеграции, AI, автоматизация, аналитика и облачные решения в рамках одной команды.

## Identity inputs

- Logo path: Использовать существующий логотип Dolphin Group. Если логотип отсутствует — временно использовать текстовый логотип. Предполагаемый путь: `/public/logo.svg`.
- Primary colors:
  - Blue 600 — `#2563EB`
  - Blue 700 — `#1D4ED8`
  - Navy — `#0F172A`
  - White — `#FFFFFF`
- Secondary colors:
  - Blue 50 — `#EFF6FF`
  - Blue 100 — `#DBEAFE`
  - Cyan 400 — `#22D3EE`
  - Slate 50 — `#F8FAFC`
  - Slate 200 — `#E2E8F0`
  - Slate 500 — `#64748B`
  - Slate 900 — `#0F172A`
- Existing font licenses: Использовать бесплатные шрифты с открытой лицензией. Предпочтительно Geist, Inter или Manrope.
- Photography style: Современные технологические изображения, интерфейсы продуктов, бизнес-процессы, облачная инфраструктура и аналитика. Не использовать шаблонные фотографии рукопожатий и людей, указывающих на экран.
- Illustration style: Минималистичные технологические иллюстрации, абстрактные схемы, интерфейсные элементы, мягкие линии и синие градиенты.
- Icon style: Линейные иконки одного стиля и одинаковой толщины. Предпочтительно Lucide React.
- Existing design-system link or files: Использовать Tailwind CSS и существующие компоненты проекта. При отсутствии дизайн-системы создать базовые токены цветов, типографики, радиусов, теней и отступов.

## Copy principles

- Vocabulary to use:
  - цифровые продукты
  - автоматизация бизнеса
  - IT-решения
  - интеграции
  - масштабируемая архитектура
  - MVP
  - облачная инфраструктура
  - AI-агенты
  - аналитика данных
  - обсудить проект
  - получить консультацию
- Vocabulary to avoid:
  - лучший в мире
  - гарантированный результат
  - революционное решение
  - мгновенный рост
  - универсальное решение для всех
  - любые неподтверждённые обещания
- Capitalization: Использовать обычный регистр предложений. Не писать заголовки и кнопки полностью заглавными буквами.
- Sentence length: Заголовки — до 8–10 слов. Описания — до 2–3 коротких предложений.
- Calls to action:
  - Обсудить проект
  - Получить консультацию
  - Посмотреть услуги
  - Рассказать о задаче
  - Связаться с нами
- Claims requiring evidence:
  - снижение расходов на хостинг на 20–30%;
  - срок запуска MVP за 30 дней;
  - количество клиентов и проектов;
  - показатели роста бизнеса;
  - отзывы;
  - партнёры;
  - награды;
  - гарантии результата.

  Использовать такие заявления только при наличии подтверждённых данных.

## Non-negotiables

- Must include:
  - название Dolphin Group;
  - понятное описание деятельности;
  - полный список услуг;
  - сильный главный экран;
  - блок преимуществ;
  - процесс работы;
  - контактную форму;
  - финальный CTA;
  - полноценный футер;
  - адаптивную мобильную версию;
  - доступные состояния hover и focus;
  - плавные анимации.
- Must avoid:
  - фотографии дельфинов;
  - детскую морскую стилистику;
  - чрезмерное количество волн;
  - шаблонный SaaS-дизайн;
  - неоновые эффекты;
  - перегруженные градиенты;
  - фальшивые отзывы;
  - вымышленные цифры и клиенты;
  - логотипы компаний без подтверждения;
  - обычные CSS-файлы, если Tailwind CSS установлен;
  - тяжёлые анимации, мешающие чтению.
- Regulatory/legal notes:
  - добавить политику конфиденциальности;
  - добавить пользовательское соглашение;
  - добавить согласие на обработку персональных данных для контактной формы;
  - не отправлять данные формы без явного уведомления пользователя;
  - не использовать неподтверждённые коммерческие обещания.
- Accessibility requirements:
  - соответствие базовым требованиям WCAG 2.1 AA;
  - достаточный контраст;
  - семантическая HTML-разметка;
  - навигация с клавиатуры;
  - видимые focus-состояния;
  - labels для полей формы;
  - поддержка `prefers-reduced-motion`;
  - минимальный размер основного текста 16 px;
  - области нажатия не меньше 44×44 px.
