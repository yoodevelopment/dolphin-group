# Ecommerce Page

## Product detail priorities

The user should quickly understand:
- product;
- price;
- variant or configuration;
- availability;
- delivery expectation;
- return/warranty terms;
- primary purchase action.

Brand storytelling must not hide these.

## Gallery

- Preserve aspect ratio.
- Support keyboard and touch.
- Provide meaningful alt text.
- Make thumbnails usable.
- Avoid auto-rotating media.
- Consider zoom only when detail matters.

## Variants

- Use actual names or visual swatches with labels.
- Make unavailable combinations clear before submission.
- Preserve selection in the URL or state when appropriate.
- Announce changes accessibly.

## Purchase area

- Keep price and CTA visually stable.
- Explain recurring charges.
- Show error and loading state.
- Do not use deceptive urgency.
- On mobile, use sticky purchase controls only when they do not cover important content.

## Category and search

Prioritize:
- findability;
- comparison;
- filters;
- availability;
- stable product cards;
- meaningful sorting.

Avoid making every product card an animation showcase.

## Checkout

Reduce surprise. Make totals, shipping, taxes, steps, and security expectations clear. Preserve entered data on recoverable errors.
