# Screenshot Review Checklist

- [ ] First viewport communicates category, promise, and action.
- [ ] Page has one clear visual thesis.
- [ ] No invented proof or placeholder accidentally shipped.
- [ ] Header and CTA remain usable at every width.
- [ ] Large type wraps deliberately.
- [ ] No horizontal overflow.
- [ ] Images do not shift layout.
- [ ] Sticky sections release correctly.
- [ ] Focus ring is visible.
- [ ] Reduced motion keeps all content.
- [ ] Footer content and legal links are reachable.
- [ ] Lint, typecheck, tests, and build pass.
