# Typography System

## Select by role

Define:
- display;
- heading;
- body;
- UI;
- mono/data if needed.

A single variable family may cover several roles. Do not add fonts merely for variety.

## Evaluate fonts

Check:
- license and delivery;
- language coverage;
- numerals;
- punctuation;
- weight range;
- readability at body size;
- personality at display size;
- performance cost.

Use system or repository fonts when they fit.

## Establish hierarchy

For each role define:
- size;
- line height;
- weight;
- tracking;
- max width;
- responsive behavior;
- optical treatment.

Use fluid sizes for large display text. Avoid excessive tracking on lowercase body text.

## Editorial controls

- Balance headings intentionally.
- Prevent awkward widows where feasible.
- Use text wraps carefully; do not hard-code breaks that fail in translation.
- Keep paragraph measure roughly 55–75 characters.
- Align numbers with tabular figures where scanning matters.
- Do not use all caps for long text.

## Accessibility

Do not depend on light font weights at low contrast. Support browser zoom and dynamic content without clipping.
