# Editorial Portfolio

## Principle

Do not turn a portfolio into a grid of identical cards. The work should control the rhythm.

## Home composition

Possible structures:
- rolling project index;
- selected work with variable scale;
- editorial cover and issue structure;
- chronological studio log;
- discipline-based navigation;
- one immersive featured project plus compact archive.

## Case study

Show:
- context;
- role;
- constraints;
- key decisions;
- process evidence;
- result;
- what changed.

Avoid long process theatre with no decisions.

## Typography and media

- Let captions and credits be first-class.
- Use consistent crop logic.
- Vary scale according to importance.
- Keep reading measure controlled.
- Use motion to connect images or reveal sequence, not to delay viewing.

## Navigation

Make it easy to:
- understand authorship;
- move between projects;
- contact or hire;
- access relevant resume/services;
- share a specific case study.

## Mobile

Preserve editorial hierarchy with crop changes, ordering, and type adjustment rather than shrinking the desktop grid.
