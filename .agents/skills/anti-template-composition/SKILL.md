# Anti-Template Composition

## Detect template symptoms

Look for:
- hero centered in a rounded container;
- eyebrow, large heading, paragraph, two buttons;
- dashboard screenshot floating below;
- logo strip;
- three equal feature cards;
- bento grid;
- three pricing cards;
- final CTA in another rounded gradient box.

These patterns are not forbidden individually. The problem is using them without product-specific reasoning.

## Transformation methods

### Replace generic feature grids

Use one of:
- annotated product walkthrough;
- before/after workflow;
- comparison matrix;
- role-based paths;
- interactive sequence;
- proof-driven case fragment;
- timeline;
- system map;
- real artifact gallery;
- progressive disclosure.

### Vary section grammar

Alternate:
- full-bleed and constrained;
- dense and sparse;
- text-led and media-led;
- static and interactive;
- light and dark;
- vertical and horizontal narrative.

Do not vary everything at once.

### Create a signature

Choose one reusable page-specific motif:
- a line that routes between steps;
- numbered editorial markers;
- a crop system;
- a measurement grid;
- shifting columns;
- a recurring annotation;
- a product-specific shape;
- an evidence stamp.

Use it consistently but not everywhere.

## Anti-cliché review

Ask:
- Does the composition reveal how the product works?
- Could this layout be recognized without the logo?
- Is each section doing a different narrative job?
- Is there enough quiet space?
- Is there one dominant moment rather than ten competing effects?
- Does mobile preserve the idea?

If most answers are no, recompose before polishing.
