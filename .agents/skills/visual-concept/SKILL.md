# Visual Concept

## Build the concept from meaning

Start from:
- product mechanism;
- customer transformation;
- brand personality;
- content format;
- visual assets;
- interaction model.

Do not start from fashionable effects.

## Concept sentence

Write one sentence in this form:

> The page feels like **[world/material/editorial mode]**, using **[governing visual device]** to make **[product truth]** immediately understandable.

Examples of governing devices:
- a live workflow that grows across the page;
- an editorial index with oversized evidence;
- a product canvas surrounded by contextual annotations;
- a time-based transformation;
- a modular system whose pieces assemble as the user scrolls;
- a cinematic field of real artifacts;
- a restrained data wall;
- a tactile catalogue.

## Direction board

Define:
- composition;
- typographic character;
- palette roles;
- texture/material;
- imagery;
- iconography;
- motion;
- section rhythm;
- mobile translation.

## Originality check

Reject a direction when:
- replacing the logo and accent color would make it fit any SaaS product;
- its signature is only a gradient or blur;
- it depends on fake content;
- it mimics a known reference's exact composition;
- the hero and every section use the same card language.

## Feasibility check

Confirm that the concept:
- can be implemented within the current stack;
- performs acceptably;
- remains legible;
- has a reduced-motion form;
- works on mobile without collapsing into a long generic stack.
