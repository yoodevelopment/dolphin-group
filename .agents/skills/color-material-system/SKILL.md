# Color and Material System

## Start with roles

Define semantic tokens:
- canvas;
- surface;
- elevated;
- text;
- muted;
- subtle;
- border;
- accent;
- accent-contrast;
- success;
- warning;
- danger;
- focus.

Map brand colors to roles rather than scattering literals.

## Palette discipline

Choose:
- one dominant neutral family;
- one primary accent;
- optional supporting accent;
- semantic colors.

Use saturation strategically. A premium interface may be vivid or quiet, but it must be controlled.

## Dark mode

Design dark mode rather than invert colors:
- reduce pure black/white extremes;
- tune borders separately;
- test imagery;
- preserve status distinction;
- avoid glowing every element.

## Material

Choose one primary surface language:
- flat editorial;
- tactile paper;
- crisp technical;
- translucent layered;
- soft volumetric;
- photographic/cinematic.

Mix materials only with clear hierarchy.

## Depth

Create depth using a combination of:
- scale;
- overlap;
- contrast;
- blur;
- shadow;
- perspective;
- motion.

Do not rely only on large shadows.

## Contrast

Check text, controls, focus, and status states. Decorative low-contrast elements must not carry essential meaning.
